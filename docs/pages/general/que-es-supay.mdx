# Supay · Facturación electrónica para Bolivia

Emite facturas válidas ante el SIAT desde tu propio sistema, por API o con el
SDK TypeScript. Sin integrar SOAP a mano, sin gestionar CUIS/CUFD a mano.

<Callout intent="info">
  Beta cerrada: solo ambiente **PILOTO** del SIAT (sin validez fiscal).
  Pre-requisito único: la API corriendo (`GET /v1/health` → `{"status":"ok"}`).
</Callout>

## Qué resuelve

| Sin Supay | Con Supay |
|---|---|
| Integrar SOAP del SIAT a mano (12 fachadas, 51 sectores) | Un `POST /v1/invoices/emit` + SDK |
| Gestionar CUIS/CUFD, firma XAdES, CUF y catálogos | Automático (setup + renovación + sincronización) |
| Contingencia offline manual | Emisión `OFFLINE` + paquetes oficiales |

## Cómo funciona (flujo día 1)

<Steps toc={true}>
  <Step title="Alta del tenant">
    La empresa se registra (NIT + razón social) y recibe su `X-API-Key`.
    Ver [Onboarding](../empezar/onboarding.mdx).
  </Step>
  <Step title="Puesta en marcha SIAT">
    Sucursal → punto de venta → certificado P12 → setup (CUIS + CUFD) →
    sincronización de catálogos.
  </Step>
  <Step title="Facturación">
    `preview` (validar) → `emit` (crear y emitir) → `ACCEPTED`. XML y PDF
    descargables. Ver [Emitir factura](../facturacion/emitir-factura.mdx).
  </Step>
  <Step title="Post-emisión">
    Consulta de estado, [anulación](../facturacion/anulacion-venta.mdx),
    [contingencia](../facturacion/contingencia.mdx) y
    [paquetes](../facturacion/paquetes-masiva.mdx).
  </Step>
</Steps>
