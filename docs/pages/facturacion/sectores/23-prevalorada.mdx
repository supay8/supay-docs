# 23 · Prevalorada

Tarjetas y pines con crédito fiscal. Regla única: **exactamente una línea** (más
de una → `400`). Sin campos sectoriales.

## Cabecera (`data`)

`data: {}` — sin campos sectoriales.

## Detalle (`items[].data`)

Una sola línea, sin campos sectoriales.
