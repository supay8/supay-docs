# 28 · Comercial de Exportación de Servicios

Exportación de servicios sin crédito fiscal. Versión liviana de la
[3 · Exportación](./03-exportacion.mdx): comprador, destino e info adicional,
sin campos de mercadería.

## Cabecera (`data`)

| Campo | Tipo | Obligatorio | Qué significa |
|---|---|---|---|
| `nim` | string | Ver perfil | Identificación del exportador |
| `direccion_comprador` | string | Ver perfil | Dirección del comprador externo |
| `lugar_destino` | string | Ver perfil | Lugar de destino |
| `pais_destino` | string | Ver perfil | País de destino |
| `incoterm` | string | Ver perfil | Término comercial |
| `informacion_adicional` | string | No | Info libre |

## Detalle (`items[].data`)

Sin campos sectoriales.
