# 6 · Servicio Turístico y Hospedaje

Turismo y hospedaje sin crédito fiscal. Igual estructura que
[16 · Hoteles](./16-hoteles.mdx) (que sí da crédito), más el operador turístico.

## Cabecera (`data`)

| Campo | Tipo | Obligatorio | Qué significa |
|---|---|---|---|
| `fecha_ingreso_hospedaje` | fecha | Ver perfil | Ingreso del huésped |
| `cantidad_habitaciones` | int | No | Habitaciones ocupadas |
| `cantidad_huespedes` | int | No | Total de huéspedes |
| `cantidad_mayores` / `cantidad_menores` | int | No | Desglose adultos/menores |
| `razon_social_operador_turismo` | string | No | Operador turístico del paquete |

## Detalle (`items[].data`)

| Campo | Tipo | Obligatorio | Para qué sirve |
|---|---|---|---|
| `detalle_huespedes` | JSON | Ver perfil | Huéspedes de la línea |
