# 3 · Comercial de Exportación

Ventas al exterior sin derecho a crédito fiscal. La cabecera lleva los **datos
logísticos y comerciales** (quién exporta, a dónde, en qué términos); el detalle
identifica la **mercadería** (NANDINA).

## Cabecera (`data`)

| Campo | Tipo | Obligatorio | Qué significa |
|---|---|---|---|
| `nim` | string | Ver perfil | Identificación del exportador |
| `ruex` | string | Ver perfil | Registro Único de Exportadores |
| `origen` | string | Ver perfil | Origen de la mercadería |
| `pais_destino` | string | Ver perfil | País de destino |
| `lugar_destino` | string | Ver perfil | Ciudad/lugar de destino |
| `puerto_destino` / `puerto_transito` | string | No | Puertos de la ruta |
| `incoterm` / `incoterm_detalle` | string | Ver perfil | Término comercial + detalle |

<AccordionGroup>
  <Accordion title="Ver el resto de campos (costos, totales FOB, bultos)">
    | Campo | Tipo | Obligatorio | Qué significa |
    |---|---|---|---|
    | `costos_gastos_nacionales` | objeto | Ver perfil | Costos y gastos nacionales (JSON) |
    | `costos_gastos_internacionales` | objeto | Ver perfil | Costos y gastos internacionales |
    | `total_gastos_nacionales_fob` / `total_gastos_internacionales` | number | Ver perfil | Totales FOB |
    | `tipo_cambio_anb` | number | Ver perfil | Tipo de cambio ANB |
    | `direccion_comprador` | string | Ver perfil | Dirección del comprador externo |
    | `informacion_adicional` | string | No | Info libre de la operación |
    | `numero_descripcion_paquetes_bultos` | string | Ver perfil | Bultos/paquetes |
  </Accordion>
</AccordionGroup>

## Detalle (`items[].data`)

| Campo | Tipo | Obligatorio | Para qué sirve |
|---|---|---|---|
| `codigo_nandina` | string | Ver perfil | Código arancelario NANDINA |
