# 44 · Importación y Comercialización de Lubricantes

Lubricantes con crédito fiscal. Igual identificación de partes que el
[19 · IEHD](./19-iehd.mdx) más la **deducción IEHD del D.S. 25530**.

## Cabecera (`data`)

| Campo | Tipo | Obligatorio | Qué significa |
|---|---|---|---|
| `monto_deduccion_iehd_ds25530` | number | Ver perfil | Deducción IEHD según D.S. 25530 |
| `ciudad` | string | Ver perfil | Ciudad de la operación |
| `nombre_propietario` | string | Ver perfil | Propietario del producto |
| `nombre_representante_legal` | string | Ver perfil | Representante legal |
| `condicion_pago` | string | Ver perfil | Condición de pago |
| `periodo_entrega` | string | Ver perfil | Periodo de entrega |

## Detalle (`items[].data`)

Sin campos sectoriales.
