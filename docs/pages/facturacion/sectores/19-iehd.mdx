# 19 · Hidrocarburos Alcanzada IEHD

Combustibles alcanzados por el IEHD, con crédito fiscal. La cabecera identifica
**quién vende a quién y bajo qué condiciones**; cada línea lleva su **% IEHD**.
Sin ambos, el SIAT rechaza.

## Cabecera (`data`)

| Campo | Tipo | Obligatorio | Qué significa |
|---|---|---|---|
| `monto_iehd` | number | Ver perfil | Monto del IEHD de la operación |
| `ciudad` | string | Ver perfil | Ciudad de la operación |
| `nombre_propietario` | string | Ver perfil | Propietario del producto |
| `nombre_representante_legal` | string | Ver perfil | Representante legal |
| `condicion_pago` | string | Ver perfil | Condición de pago pactada |
| `periodo_entrega` | string | Ver perfil | Periodo de entrega |

## Detalle (`items[].data`)

| Campo | Tipo | Obligatorio | Para qué sirve |
|---|---|---|---|
| `porcentaje_iehd` | number | Ver perfil | % IEHD aplicado a la línea |
