# 49 · Telecomunicaciones Zona Franca

Igual que el [22 · Telecomunicaciones](./22-telecomunicaciones.mdx)
(`nit_conjunto` + serie/IMEI) pero **sin** crédito fiscal, por fachada propia.

## Cabecera (`data`)

| Campo | Tipo | Obligatorio | Qué significa |
|---|---|---|---|
| `nit_conjunto` | int | No | NIT conjunto para facturación agregada |

## Detalle (`items[].data`)

| Campo | Tipo | Obligatorio | Para qué sirve |
|---|---|---|---|
| `numero_serie` | string | No | Serie del equipo |
| `numero_imei` | string | No | IMEI del equipo |
