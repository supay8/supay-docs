# 50 · Hospitales / Clínicas Zona Franca

Igual que el [17 · Salud](./17-salud.mdx) (modalidad + médico por línea) pero
**sin** crédito fiscal.

## Cabecera (`data`)

| Campo | Tipo | Obligatorio | Qué significa |
|---|---|---|---|
| `modalidad_servicio` | string | No | Modalidad (ej. "Ambulatorio") |

## Detalle (`items[].data`)

| Campo | Tipo | Obligatorio | Para qué sirve |
|---|---|---|---|
| `nombre_apellido_medico` | string | Ver perfil | Médico tratante |
| `nit_documento_medico` | string | Ver perfil | Documento del médico |
| `nro_matricula_medico` | string | Ver perfil | Matrícula profesional |
| `especialidad` | string | Ver perfil | Especialidad |
