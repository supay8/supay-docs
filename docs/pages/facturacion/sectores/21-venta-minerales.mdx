# 21 · Venta de Minerales

Venta interna de minerales con crédito fiscal. Igual trazabilidad que la
[20 · Exportación minera](./20-exportacion-minera.mdx), más liquidación e IVA
de la operación interna.

## Cabecera (`data`)

| Campo | Tipo | Obligatorio | Qué significa |
|---|---|---|---|
| `origen` | string | Ver perfil | Origen del mineral |
| `puerto_destino` / `puerto_transito` | string | Ver perfil | Puertos |
| `incoterm` | string | Ver perfil | Término comercial |
| `tipo_cambio_anb` | number | Ver perfil | Tipo de cambio ANB |
| `concentrado_granel` | string | Ver perfil | Concentrado o granel |
| `kilos_netos_humedos` / `kilos_netos_secos` | number | Ver perfil | Pesos |

## Detalle (`items[].data`)

| Campo | Tipo | Obligatorio | Para qué sirve |
|---|---|---|---|
| `codigo_nandina` | string | Ver perfil | Arancel del mineral |
| `descripcion_leyes` | string | Ver perfil | Leyes del mineral |
| `cantidad_extraccion` | number | Ver perfil | Cantidad extraída |
| `unidad_medida_extraccion` | string | Ver perfil | Unidad de extracción |
