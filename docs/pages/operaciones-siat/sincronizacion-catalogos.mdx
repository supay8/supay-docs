# Sincronización de catálogos

Descarga los catálogos SIAT (monedas, pagos, unidades, actividades, productos,
leyendas...) al tenant. Sin catálogos listos, `emit` responde `409`: este es el
paso que más olvidos causa. Verifica siempre con `readiness`.

**En esta página aprenderás:** sincronizar todo o por operación, verificar readiness y consultar catálogos · **Prerrequisitos:** setup con CUIS/CUFD · **Tiempo:** ~10 min.

<Tabs>
  <Tab title="SDK TypeScript" language="typescript">
    ```typescript
    // Todo de una vez (recomendado tras el setup)
    const sync = await supay.siat.syncCatalogs({ pointOfSaleId: pos.id });
    // sync.operations[]: { operation, codigos, status, rows_saved }
    // sync.readiness: { ready, missing }

    // Una sola operación
    const solo = await supay.siat.syncCatalogs({
      pointOfSaleId: pos.id,
      operation: "tipoMoneda",
    });

    // Verificar qué falta
    const ready = await supay.catalogs.getReadiness({
      id: company.id,
      point_of_sale_id: pos.id,
    });
    // ready.ready === true, ready.missing === []
    ```
  </Tab>
  <Tab title="REST API" language="curl">
    ```bash
    # Todo de una vez
    curl -s -X POST "$BASE/v1/siat/sincronizar/$POS" \
      -H "X-API-Key: $KEY" \
      -H "Content-Type: application/json" \
      -d '{}' | jq '.operations, .readiness'

    # Una sola operación
    curl -s -X POST "$BASE/v1/siat/sincronizar/$POS?operation=tipoMoneda" \
      -H "X-API-Key: $KEY" \
      -H "Content-Type: application/json" \
      -d '{}'

    # Verificar
    curl -s "$BASE/v1/companies/$CID/catalogs/readiness?point_of_sale_id=$POS" \
      -H "X-API-Key: $KEY" | jq '{ready, missing}'
    ```
  </Tab>
</Tabs>

## Operaciones (`?operation=`)

Valor desconocido → `400`. Sin el parámetro sincroniza todo.

| Operación | Sincroniza |
|---|---|
| `tipoPuntoVenta` | Tipos de punto de venta |
| `tipoMoneda` | Monedas |
| `tipoMetodoPago` | Métodos de pago |
| `tipoDocumentoIdentidad` | Documentos de identidad |
| `tipoEmision` | Tipos de emisión |
| `tiposFactura` | Tipos de factura |
| `tipoHabitacion` | Tipos de habitación |
| `tipoDocumentoSector` | Sectores por documento |
| `unidadMedida` | Unidades de medida |
| `motivoAnulacion` | Motivos de anulación |
| `paisOrigen` | Países de origen |
| `eventosSignificativos` | Eventos significativos |
| `mensajesServicios` | Mensajes de servicios |
| `actividades` | Actividades económicas |
| `productosServicios` | Productos y servicios |
| `leyendasFactura` | Leyendas de factura |
| `actividadesDocumentoSector` | Actividades por sector |
| `fechaHora` | Fecha y hora SIAT |
| `verificarComunicacion` | Verificación de comunicación |

## Catálogos crudos y de emisión

| Recurso | Uso |
|---|---|
| `GET /siat/catalogs` y `/siat/catalogs/{tipo}` | Lectura directa de lo sincronizado (revisar) |
| `GET /companies/{id}/catalogs/productos-sin` | Buscar `codigo_producto_sin` para tus ítems |
| `GET /companies/{id}/catalogs/emision-bootstrap` | Todo lo de emisión de una vez (actividades, sectores, leyendas, monedas, pagos) |
