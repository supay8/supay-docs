# SDKs de Supay

Los SDKs de Supay se generan desde el mismo OpenAPI que documenta la API
(`supay-v1.openapi.yml`): **son un reflejo 1:1** — mismos endpoints, mismos
nombres (`x-fern-sdk-method-name`), mismos campos en camelCase. Si un ejemplo de
la documentación y el SDK difieren, manda el SDK regenerado.

## Cómo se versionan

- El contrato canónico es `supay-v1.openapi.yml` en este repo.
- Tras cada cambio del OpenAPI, regenera el SDK y compílalo antes de publicar.
- El SDK nunca se edita a mano: todo cambio entra por el OpenAPI.

```bash
# Desde la raíz de supay-docs
fern generate --local --group local --force
(cd sdks/typescript && npm run build)
```
