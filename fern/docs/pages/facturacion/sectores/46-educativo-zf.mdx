# 46 · Sector Educativo Zona Franca

Igual que el [11 · Educativo](./11-educativo.mdx) (estudiante + periodo) pero
**sin** crédito fiscal. Usa `invoiceType: "education"`.

## Cabecera (`data`)

| Campo | Tipo | Obligatorio | Qué significa |
|---|---|---|---|
| `nombre_estudiante` | string | Ver perfil | Estudiante al que se factura |
| `periodo_facturado` | string | Ver perfil | Periodo, formato `2026-10` |

## Detalle (`items[].data`)

Sin campos sectoriales.
