Combustible sin subvención, con crédito fiscal. Cabecera con **autorización,
vehículo y envase**.

## Cabecera (`data`)

| Campo | Tipo | Obligatorio | Qué significa |
|---|---|---|---|
| `codigo_autorizacion_sc` | string | Ver perfil | Autorización SC |
| `codigo_pais` | string | Ver perfil | País de la operación |
| `observacion` | string | No | Observación libre |
| `placa_vehiculo` | string | Ver perfil | Placa del vehículo |
| `tipo_envase` | string | Ver perfil | Tipo de envase |

## Detalle (`items[].data`)

Sin campos sectoriales.
