# 43 · Comercial de Exportación Hidrocarburos

Exportación de hidrocarburos sin crédito fiscal. Cabecera con **costos,
incoterm y destino**; sin NANDINA (a diferencia de la
[3 · Exportación](./03-exportacion.mdx)).

## Cabecera (`data`)

| Campo | Tipo | Obligatorio | Qué significa |
|---|---|---|---|
| `nim` | string | Ver perfil | Identificación del exportador |
| `costos_gastos_nacionales` | objeto | Ver perfil | Costos nacionales (JSON) |
| `costos_gastos_internacionales` | objeto | Ver perfil | Costos internacionales |
| `total_gastos_nacionales_fob` / `total_gastos_internacionales` | number | Ver perfil | Totales FOB |
| `incoterm` / `incoterm_detalle` | string | Ver perfil | Término + detalle |
| `lugar_destino` / `puerto_destino` | string | Ver perfil | Destino |
| `direccion_comprador` | string | Ver perfil | Comprador externo |
| `monto_detalle` | number | Ver perfil | Monto de detalle |
| `numero_descripcion_paquetes_bultos` | string | Ver perfil | Bultos |
| `informacion_adicional` | string | No | Info libre |

## Detalle (`items[].data`)

Sin campos sectoriales.
