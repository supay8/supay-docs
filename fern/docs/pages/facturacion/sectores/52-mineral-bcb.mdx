# 52 · Venta de Minerales al BCB [Experimental]

<Callout intent="warning">
  Experimental y **solo modalidad electrónica**. Solo PILOTO, como feedback de
  producto.
</Callout>

Venta de minerales al Banco Central, sin crédito fiscal. Trazabilidad minera
completa como la [21 · Venta de Minerales](./21-venta-minerales.mdx).

## Cabecera (`data`)

| Campo | Tipo | Obligatorio | Qué significa |
|---|---|---|---|
| `concentrado_granel` | string | Ver perfil | Concentrado o granel |
| `gastos_realizacion` | number | Ver perfil | Gastos de realización |
| `humedad_porcentaje` / `humedad_valor` | number | Ver perfil | Humedad |
| `iva` | number | Ver perfil | IVA de la operación |
| `kilos_netos_humedos` / `kilos_netos_secos` | number | Ver perfil | Pesos |
| `liquidacion_preliminar` | string | Ver perfil | Liquidación preliminar |
| `merma_porcentaje` / `merma_valor` | number | Ver perfil | Merma |
| `numero_lote` | string | Ver perfil | Lote |
| `origen` | string | Ver perfil | Origen del mineral |
| `otros_datos` | string | Ver perfil | Datos extra |
| `sub_total` | number | Ver perfil | Subtotal operativo |

## Detalle (`items[].data`)

| Campo | Tipo | Obligatorio | Para qué sirve |
|---|---|---|---|
| `codigo_nandina` | string | Ver perfil | Arancel del mineral |
