# 12 · Comercialización de Hidrocarburos

Estaciones y distribuidoras, con crédito fiscal. La cabecera lleva
**autorización, vehículo y envase**; sin detalle sectorial.

## Cabecera (`data`)

| Campo | Tipo | Obligatorio | Qué significa |
|---|---|---|---|
| `codigo_autorizacion_sc` | string | Ver perfil | Autorización SC de la estación |
| `codigo_pais` | string | Ver perfil | País de la operación |
| `observacion` | string | No | Observación libre |
| `placa_vehiculo` | string | Ver perfil | Placa del vehículo abastecido |
| `tipo_envase` | string | Ver perfil | Tipo de envase |

## Detalle (`items[].data`)

Sin campos sectoriales.
