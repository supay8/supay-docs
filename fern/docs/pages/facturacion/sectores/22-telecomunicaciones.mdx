# 22 · Telecomunicaciones

Telefonía, internet y datos con crédito fiscal. Va por **fachada propia**. La
cabecera lleva el **NIT conjunto**; el detalle identifica **equipos por
serie/IMEI**.

## Cabecera (`data`)

| Campo | Tipo | Obligatorio | Qué significa |
|---|---|---|---|
| `nit_conjunto` | int | No | NIT conjunto para facturación agregada de líneas |

## Detalle (`items[].data`)

| Campo | Tipo | Obligatorio | Para qué sirve |
|---|---|---|---|
| `numero_serie` | string | No | Serie del equipo entregado |
| `numero_imei` | string | No | IMEI del equipo |
