# 48 · Nota Crédito Débito ICE

Ajustes sobre ICE por DocumentoAjuste. Como el
[47 · Descuentos](./47-nota-descuentos.mdx) más los **datos ICE** (marca,
alícuotas y montos por línea). Exige `referenceInvoiceId`.

## Cabecera (`data`)

| Campo | Tipo | Obligatorio | Qué significa |
|---|---|---|---|
| `monto_total_devuelto` | number | Ver perfil | Total devuelto |
| `monto_descuento_credito_debito` | number | Ver perfil | Descuento del ajuste |
| `monto_efectivo_credito_debito` | number | No | Override del crédito calculado |
| `numero_nota_credito_debito` | string/int | Ver perfil | Número del documento |

## Detalle (`items[].data`)

| Campo | Tipo | Obligatorio | Para qué sirve |
|---|---|---|---|
| `marca_ice` | string | Ver perfil | Marca del producto ICE |
| `cantidad_ice` | number | Ver perfil | Cantidad base ICE |
| `precio_neto_venta_ice` | number | Ver perfil | Precio neto base ICE |
| `alicuota_iva` | number | Ver perfil | Alícuota IVA |
| `alicuota_especifica` / `alicuota_porcentual` | number | Ver perfil | Alícuotas ICE |
| `monto_ice_especifico` / `monto_ice_porcentual` | number | Ver perfil | ICE de la línea |
