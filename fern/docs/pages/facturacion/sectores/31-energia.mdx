# 31 · Suministro de Energía

Energía (no domiciliaria regulada como el 13), con crédito fiscal. Cabecera con
país, placa y envase; sin detalle sectorial.

## Cabecera (`data`)

| Campo | Tipo | Obligatorio | Qué significa |
|---|---|---|---|
| `codigo_pais` | string | Ver perfil | País de la operación |
| `placa_vehiculo` | string | Ver perfil | Placa asociada al suministro |
| `tipo_envase` | string | Ver perfil | Tipo de envase |

## Detalle (`items[].data`)

Sin campos sectoriales.
