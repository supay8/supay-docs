# 30 · Boleto Aéreo

Pasajes aéreos sin crédito fiscal. Particularidades: **sin detalle** (el XSD solo
define cabecera), **solo emisión masiva** (nunca individual) y admite borrador
sin `items` (con `total` + pasajero).

<Callout intent="warning">
  `sector: "30"` en emisión individual → `400 "requiere emisión masiva"`. Es la
  única vía: `POST /v1/siat/bulk/{posId}`.
</Callout>

## Cabecera (`data`)

| Campo | Tipo | Obligatorio | Qué significa |
|---|---|---|---|
| `nombre_pasajero` | string | Sí | Pasajero del boleto |
| `numero_documento_pasajero` | string | Sí | Documento del pasajero |
| `codigo_iata_linea_aerea` | int | No | IATA de la aerolínea |
| `codigo_iata_agente_viajes` | string | No | IATA de la agencia |
| `nit_agente_viajes` | int | No | NIT de la agencia |
| `codigo_origen_servicio` | string | No | Origen del servicio |
| `codigo_tipo_transaccion` | string | No | Tipo de transacción |
| `monto_tarifa` | number | No | Tarifa del boleto |

## Detalle

Sin detalle: el boleto no tiene líneas.
