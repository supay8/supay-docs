# 17 · Hospitales / Clínicas

Salud con crédito fiscal. La cabecera lleva la **modalidad del servicio**; el
detalle identifica **médico y acto médico por línea**.

## Cabecera (`data`)

| Campo | Tipo | Obligatorio | Qué significa |
|---|---|---|---|
| `modalidad_servicio` | string | No | Modalidad (ej. "Ambulatorio") |

## Detalle (`items[].data`)

| Campo | Tipo | Obligatorio | Para qué sirve |
|---|---|---|---|
| `nombre_apellido_medico` | string | Ver perfil | Médico tratante |
| `nit_documento_medico` | string | Ver perfil | Documento del médico |
| `nro_matricula_medico` | string | Ver perfil | Matrícula profesional |
| `especialidad` / `especialidad_detalle` / `especialidad_medico` | string | Ver perfil | Especialidad |
| `nro_quirofano_sala_operaciones` | string | Ver perfil | Quirófano/sala |
| `nro_factura_medico` | string | Ver perfil | Factura del médico |
