# 40 · Servicios Básicos Zona Franca

Igual estructura que el [13 · Servicios Básicos](./13-servicios-basicos.mdx)
(medidor, periodo, consumo, ajustes, tasas) pero **sin** crédito fiscal.

## Cabecera (`data`)

| Campo | Tipo | Obligatorio | Qué significa |
|---|---|---|---|
| `numero_medidor` | string | Ver perfil | Medidor del suministro |
| `domicilio_cliente` | string | Ver perfil | Domicilio del suministro |
| `ciudad` / `zona` | string | Ver perfil | Ciudad y zona |
| `mes` / `gestion` | string | Ver perfil | Periodo del consumo |
| `consumo_periodo` | number | Ver perfil | Consumo del periodo |
| `beneficiario_ley_1886` | string | Ver perfil | Beneficiario Ley 1886 |
| `monto_descuento_ley_1886` | number | Ver perfil | Descuento Ley 1886 |
| `monto_descuento_tarifa_dignidad` | number | Ver perfil | Descuento tarifa dignidad |
| `ajuste_sujeto_iva` / `ajuste_no_sujeto_iva` | number | Ver perfil | Ajustes (+ sus `detalle_...`) |
| `tasa_alumbrado` / `tasa_aseo` / `otras_tasas` | number | Ver perfil | Tasas municipales |

## Detalle (`items[].data`)

Sin campos sectoriales.
