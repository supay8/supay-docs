# Quickstart (5 min)

Emite tu primera factura en **PILOTO**. Pre-requisitos: API corriendo
(`GET /v1/health` → `{"status":"ok"}`), una `X-API-Key` válida y un punto de venta
con CUIS/CUFD vigente. Sin tenant todavía: [Onboarding](./onboarding.mdx).

<Callout intent="warning">
  Cada `POST` de creación inicia otra factura (no hay `Idempotency-Key`). Guarda
  siempre `id` + `cuf` y concilia por ID. Nunca reintentes un `emit` a ciegas.
</Callout>

## Qué hacer con cada estado

| `status` | Significado | Acción |
|---|---|---|
| `ACCEPTED` | Aceptada por el SIAT | Guardar `id` + `cuf`. Descargar XML/PDF. |
| `OBSERVED` | Aceptada con observaciones | Leer `siat_mensajes`, no re-emitir. |
| `OFFLINE` | Timeout/caída SIAT, firmada local (`codigoEmision=2`) | Guardar XML + `contingency_event_id`. Ver [Contingencia](../facturacion/contingencia.mdx). |
| `REJECTED` | Rechazada por el SIAT | Corregir y **crear una factura nueva** (no se reencola). |

## Ciclo completo

<Tabs>
  <Tab title="SDK TypeScript" language="typescript">
    ```typescript
    // Leer y re-verificar contra el SIAT
    const inv = await supay.invoices.get({ id });
    const reverificado = await supay.invoices.getSiatStatus({ id });

    // Artefactos fiscales
    const xml = await supay.invoices.downloadXml({ id }); // XML firmado
    const pdf = await supay.invoices.downloadPdf({ id }); // on-demand si hay CUF

    // Anular con motivo del catálogo SIAT
    await supay.invoices.annul({ id, codigo_motivo: 1 });
    ```
  </Tab>
  <Tab title="REST API" language="curl">
    ```bash
    curl -s "$BASE/v1/invoices/$ID" -H "X-API-Key: $KEY"
    curl -s "$BASE/v1/invoices/$ID/siat-status" -H "X-API-Key: $KEY"

    curl -s "$BASE/v1/invoices/$ID/xml" -H "X-API-Key: $KEY" -o factura.xml
    curl -s "$BASE/v1/invoices/$ID/pdf" -H "X-API-Key: $KEY" -o factura.pdf

    curl -s -X POST "$BASE/v1/invoices/$ID/annul" \
      -H "X-API-Key: $KEY" \
      -H "Content-Type: application/json" \
      -d '{"codigo_motivo": 1}'
    ```
  </Tab>
