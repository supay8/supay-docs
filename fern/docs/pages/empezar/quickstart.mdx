# Quickstart

Una vez creada tu API key y configurado el POS, emitir requiere una llamada:

```typescript
import { Supay } from "@supay/sdk";

const supay = new Supay({ apiKey: process.env.SUPAY_API_KEY! });
const invoice = await supay.invoices.emit({
  posId: process.env.SUPAY_POS_ID!,
  customer: { documentType: "ci", documentNumber: "1234567", name: "Ada Lovelace" },
  items: [{ sku: "PRO", description: "Plan profesional", codigoActividad: "101010",
    codigoProductoSin: 5113100, unidadMedida: 58, quantity: 1, price: 150 }],
});
console.log(invoice.id, invoice.status, invoice.cuf);
```

[Configura la empresa y su POS](./onboarding.mdx) antes de emitir.
[Consulta pagos, sectores y ajustes](../facturacion/emitir-factura.mdx).
Cada emisión crea una factura nueva; conserva el ID para consultar estado,
XML, PDF o anularla. `OFFLINE` se concilia por paquetes cuando vuelve la conexión.
