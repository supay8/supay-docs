# Autenticación

Las integraciones usan `X-API-Key`. Cada key pertenece a una empresa.

```typescript
import { Supay } from "@supay/sdk";
const supay = new Supay({ apiKey: process.env.SUPAY_API_KEY! });
```

Los usuarios usan `Authorization: Bearer <jwt>`. En rutas de negocio, añade
`X-Company-ID` para seleccionar una empresa de la que seas miembro. En rutas
`/companies/{id}/...`, la empresa ya está en la URL.

En self-hosted, registra una cuenta con `POST /v1/auth/signup` o inicia sesión
con `POST /v1/auth/login`. En cloud, usa la sesión de Better Auth configurada.
Crea una empresa con `POST /v1/auth/companies` y crea su API key con
`POST /v1/companies/{id}/api-keys`, ambos con Bearer.

La creación devuelve `apiKey` una sola vez: consérvala para tu integración.
No se requiere un secreto global del backend.
