# Configurar empresa y punto de venta

1. Inicia sesión y conserva tu Bearer token.
2. Crea una empresa con `POST /v1/auth/companies` y un cuerpo como
   `{"nit":"123456789","businessName":"Mi Empresa SRL","ambiente":"PILOTO"}`.
3. Crea una API key con `POST /v1/companies/{id}/api-keys` y
   `{"name":"integración"}`. Usa `apiKey` como `X-API-Key` en los siguientes pasos.
4. Crea una sucursal con `POST /v1/branches` enviando `companyId`, `name` y
   `codigoSucursal`. Crea el POS con `POST /v1/pos` enviando `branchId` y `name`.
5. Configura las credenciales y el certificado de la empresa, y ejecuta
   `POST /v1/setup` con `{"posId":"<id-del-pos>"}` para CUIS, catálogos y CUFD.
6. Emite con `POST /v1/invoices/emit`.

El tenant se obtiene de la credencial. Las operaciones SIAT reciben `posId`
y las validaciones de paquetes reciben `batchId`.
