# Enviar compras

Informa tus compras al SIAT por lote comprimido (recepción de compras). Es el
flujo inverso a emitir: aquí reportas lo que **compraste**.

| Campo | Tipo | Obligatorio | Qué significa |
|---|---|---|---|
| `descripcion` | string | Ver perfil | Descripción del lote |
| `tipoCompra` | int | Ver perfil | Tipo de compra SIAT |
| `archivo` | string | Ver perfil | Lote comprimido (base64) |
| `hashArchivo` | string | Ver perfil | SHA del archivo |
| `cantidadFacturas` | int | Ver perfil | Facturas del lote |
| `gestion` / `periodo` | int | Ver perfil | Gestión y periodo |
| `fechaEnvio` | fecha | Ver perfil | Fecha de envío (ISO 8601) |
